# Gree Fan

格力独立风扇的 Home Assistant 局域网集成。它不会把空调的送风模式当成风扇。

## 设备识别

集成优先使用发现报文中的 `mid`，支持已确认的 `828200`、`828202`、
`828203`、`828204`、`828205`、`828208`、`828209`、`828210`、`828211`、
`828212` 和 `828214`。其他 `8282xx` 型号只启用电源、风速和基础模式字段。

没有 `mid` 时，只接受已知的精确型号，或发现报文明确标记为
`fan` / `fan_x` / `风扇` 的设备。设备显示名称不用于猜测类型。

## 按型号启用功能

- 风速按 3、8 或 12 档映射。
- 只有上报 `Rotate` 的型号显示左右摆风。
- 只有 `828209` 使用已校准的 60° / 80° / 100° 角度选择。
- 只有上报 `SwUpDn` 的型号显示上下摆风开关。`828209` 开启时会同时初始化为 90 度，无需先在 App 中操作。
- 只有同时上报四个 `Tmr*` 字段的型号显示原生定时。

集成使用与 Home Assistant 官方 Gree Climate 相同的 `greeclimate==2.1.4`，
可自动尝试 v1 和 v2 加密绑定。
